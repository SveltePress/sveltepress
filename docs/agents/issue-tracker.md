# Issue Tracker

SveltePress uses GitHub Issues in `SveltePress/sveltepress` for specifications, implementation tickets, bugs, and feature requests.

Publish a specification as a GitHub issue with the `ready-for-agent` label. Publish implementation tickets as separate GitHub issues in dependency order and record blocking issue numbers in each ticket body.

Do not use local `.scratch` tickets unless GitHub is unavailable and the task explicitly permits a local fallback.
