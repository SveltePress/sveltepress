# Triage Labels

Use these GitHub labels as the canonical triage states:

- `needs-triage`: reported work has not been classified or verified
- `needs-info`: progress requires information from the reporter or another stakeholder
- `ready-for-agent`: the issue is specified and can be implemented without another product decision
- `ready-for-human`: the issue requires a human-only action or decision
- `wontfix`: the project has decided not to implement the issue

Apply exactly one triage-state label when triaging an issue. Other descriptive labels such as `bug`, `enhancement`, and `documentation` can coexist with the triage state.
