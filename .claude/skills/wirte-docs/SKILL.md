# Documentation

- **Write Docs**: Create or update documentation in the merged docs site for every locale (EN `/`, ZH `/zh/`, BN `/bn/`) in the same change
- **Code Examples**: Generate working code examples for documentation
- **API Documentation**: Document functions, components, and APIs
- **Migration Guides**: Create guides for version upgrades
- **Versions**: If the official docs need a frozen snapshot, run the versions CLI for every locale (`/v`, `/zh/v`, `/bn/v`). See [`docs/agents/implementation.md`](../../docs/agents/implementation.md)
