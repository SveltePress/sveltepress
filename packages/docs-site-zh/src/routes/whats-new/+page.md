本站暂未启用文档版本快照，因此本页只保留与其他语言站一致的路由。

启用版本管理后，可以在任意页面导入变化总览组件：

```svelte
<script>
  import VersionChanges from '@sveltepress/theme-default/VersionChanges.svelte'
</script>

<VersionChanges />
```

完整配置请参阅[文档版本管理](/guide/version-management/)。
